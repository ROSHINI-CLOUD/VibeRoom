# Research Summary

The project should optimize for a reliable multiplayer experience, not infrastructure novelty. Managed Supabase services cover the backend needs; the hard engineering value belongs in taste modeling, deterministic ranking, fairness, VibeBridge, and explainability.

Smart Lyrics is the strongest complementary surface because it remains useful when the user is not actively in a group session.

The MVP must have a demo fallback path independent of live external catalog/provider availability.
