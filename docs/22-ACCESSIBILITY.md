# Accessibility

## Baseline

- semantic buttons/inputs;
- all interactive controls keyboard reachable;
- visible focus states;
- no color-only meaning;
- labels for reaction icons;
- minimum comfortable touch target;
- sufficient text/background contrast;
- reduced-motion media query respected.

## Lyrics

Current line highlight must have more than color alone if possible (weight/position/indicator).

## Charts

Taste DNA and Room Health require textual equivalents. A radar/visual graph cannot be the only representation.

## Live updates

Avoid noisy screen-reader announcements for every reaction. Reserve polite live regions for important room/track state.
