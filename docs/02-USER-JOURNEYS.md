# User Journeys

## A. Host creates a room

Home → Create Room → enter/display name → room generated → QR/code visible → wait for members → see ready status → Start VibeRoom.

## B. Member joins

Scan QR → display name → onboarding if no usable profile → room lobby → ready.

## C. Taste calibration

Languages → artists → 8-ish quick song reactions → context → energy → discovery slider → Taste DNA → confirm/edit.

Principle: no screen should feel like a form. Use quick, visual decisions.

## D. Live room

Now Playing → reaction row → vibe direction → optional secret request → live room pulse → lyrics/taste details as secondary surfaces.

## E. Secret request

Tap Secret Request → search/select song, artist, or intent → submit → confirmation only to requester → engine considers it later → requester may get a subtle “your request landed” acknowledgement after fulfillment.

Never expose who requested a track to the room by default.

## F. Smart Lyrics

Open Lyrics → synced line follows playback → tap line/action → Translate / Explain → save Lyric Moment.

## G. Failure journeys

- room expired → clear rejoin/create CTA;
- host disconnects → room pauses and explains recovery; host handoff is future unless implemented deliberately;
- provider track unavailable → skip candidate and select fallback;
- lyrics unavailable → show “lyrics unavailable” rather than hallucinated lyrics;
- realtime reconnect → show brief reconnecting status, restore durable room state.
