# BACKLOG

- Taste Match between two friends.
- “Between These Songs” semantic discovery.
- Music Memories / session time capsules.
- Better multilingual lyric interpretation.
- Optional accounts and cross-room taste history.
- Host handoff.

- Provider-agnostic playback handoff.
- Near-synchronized headphone mode.
- Offline/PWA behavior.
- Learned personalization once enough consented interaction data exists.

## Explicitly avoid during hackathon

- training a recommendation model from scratch;
- phone-speaker synchronization;
- huge social network features;
- unauthorized music downloading.
