# Glossary

**AI DJ** — recommendation/orchestration engine choosing the next tracks for the room.

**Taste DNA** — human-readable summary of a user's music preferences.

**Room Taste** — aggregate session model derived from members plus context.

**Fairness Debt** — signal that a member has received weaker matches recently.

**VibeBridge** — transition logic that moves gradually from current vibe to target vibe.

**Secret Request** — private request that influences ranking without public disclosure.

**Room Health** — summary of satisfaction, fairness, energy, and discovery.

**Broadcast** — realtime low-latency event path.

**Presence** — realtime connected-member state.

**Durable State** — Postgres data that must survive refresh/reconnect.

**Provider Adapter** — stable internal interface around an external music/lyrics service.
