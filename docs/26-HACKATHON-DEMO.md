# Hackathon Demo Plan

## 4-minute flow

### 0:00–0:30 — Problem
“Every group has one person controlling the AUX. Collaborative playlists still don't understand fairness or live room mood.”

### 0:30–1:10 — Join
Create room → judges/friends scan QR → each does fast calibration.

### 1:10–1:40 — Taste intelligence
Show personal Taste DNA and combined room profile.

### 1:40–2:30 — Live AI DJ
Start track on host. Everyone reacts. Show Room Health changing.

### 2:30–3:05 — Fairness + VibeBridge
Explain that one member has low recent coverage → next ranking shifts while preserving group fit. Trigger “Chill down” or another target and show gradual transition.

### 3:05–3:30 — Secret request
Submit hidden request; show only requester acknowledgement. Explain later fulfillment.

### 3:30–3:50 — Smart Lyrics
Open synchronized lyrics and demonstrate one Translate/Explain action.

### 3:50–4:00 — Close
“VibeRoom isn't an AI playlist. It's a live group music system that keeps learning the room.”

## Demo fallback

Have:
- seed catalog;
- preset 4 demo personas;
- prepared room;
- cached lyrics sample permitted for demo;
- deterministic recommendation fixtures.

External provider failure must not end the demo.
